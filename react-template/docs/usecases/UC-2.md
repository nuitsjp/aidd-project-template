# UC-2. 複数のメモを確認して一括登録する

主アクター: 利用者。目的: 複数のメモを確認後にまとめて保存する。

## 主成功系列（UC-2-M、UI確認: 要）

1. 利用者が改行区切りのタイトルと共通本文を入力する。
2. システムが形式と件数を検証し、確認画面を表示する（この時点では未保存）。
3. 利用者が一括登録を指示する。
4. システムが再検証し、全件を単一トランザクションで保存する。
5. 確定件数を表示し、一覧へ戻れるようにする。

## 拡張

| 系列 ID | 条件 | 動作 | UI確認 |
| --- | --- | --- | --- |
| UC-2-X1 | 既存タイトル衝突等で途中更新が失敗 | 全件ロールバックし、確認内容と下書きを維持 | 要 |

受け入れ条件: プレビュー段階で DB を更新しないこと。成功時は全件追加、失敗時は既存データのみが残ること。画面遷移時に入力下書きを維持すること。

実現パターン: [UCP-2](../architecture.md#patterns)。件数上限は [プロジェクト定義の制約](../project.md#constraints) を参照します。
