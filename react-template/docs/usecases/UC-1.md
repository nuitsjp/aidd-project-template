# UC-1. メモを作成・編集して保存する

主アクター: 利用者。目的: 自身のメモを保存し、後から参照・編集する。

## 主成功系列（UC-1-M、UI確認: 要）

1. 利用者が自身のメモ一覧を表示する。
2. 新規メモまたは既存メモを選択し、タイトル・本文を入力する。
3. 保存を指示する。
4. システムが入力を検証し、SQLite へ更新を確定する。
5. システムが保存結果を表示し、一覧を更新する。

## 拡張

| 系列 ID | 条件 | 動作 | UI確認 |
| --- | --- | --- | --- |
| UC-1-X1 | 入力不正・タイトル重複 | DB を更新せず、下書きと失敗理由を表示 | 要 |
| UC-1-X2 | 利用者が削除を選択 | 確認後に削除を確定 | 要 |
| UC-1-X3 | 別利用者がアクセス | 他者のデータを参照・更新不可 | 要 |
| UC-1-X4 | 既存メモが別対話で更新済み | 競合を表示し、下書きを維持 | 要 |

受け入れ条件: 画面表示だけでなく SQLite の所有者・値・版が確定し、再起動後も保持されること。古い版の上書きや他者のデータ操作を拒否すること。別タブへは確定後通知で一覧が追従すること。
