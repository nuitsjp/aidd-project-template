# UC-1. メモを作成・編集して保存する

- 主アクターと目的: 利用者が自身のメモを保存し、後から参照・編集する（[プロジェクトの目的と範囲](../project.md) との対応）
- 前提（任意）: 利用者として識別されている（参照実装ではローカル用のユーザー選択）
- 主成功系列（UC-1-M、UI 確認: 要）:

| 手順 | アクター | 操作・処理 |
| --- | --- | --- |
| 1 | 利用者 | 自身のメモ一覧を表示する |
| 2 | 利用者 | 新規メモまたは既存メモを選択し、タイトル・本文を入力する |
| 3 | 利用者 | 保存を指示する |
| 4 | システム | 入力を検証し、SQLite へ更新を確定する |
| 5 | システム | 保存結果を表示し、一覧を更新する |

- 拡張（系列 ID の末尾は -X1 から。着手した系列のみ記載）:

| 系列 ID | 分岐点 | 条件 | 動作 | UI 確認 | 理由 |
| --- | --- | --- | --- | --- | --- |
| UC-1-X1 | 4 | 入力不正・タイトル重複 | DB を更新せず、下書きと失敗理由を表示する | 要 | 失敗理由の見せ方と下書きの扱いを決める |
| UC-1-X2 | 2 | 利用者が削除を選択 | 確認後に削除を確定する | 要 | 確認操作の流れを決める |
| UC-1-X3 | 1 | 別の利用者がアクセス | 他者のメモを参照・更新できない | 要 | 所有者分離の見え方を決める |
| UC-1-X4 | 4 | 既存メモが別の対話で更新済み | 競合を表示し、下書きを維持する | 要 | 競合時の画面の振る舞いを決める |

- 受け入れ条件: 画面表示だけでなく SQLite の所有者・値・版が確定し、再起動後も保持されること。古い版の上書きや他者のデータ操作を拒否すること。別タブへは確定後の通知で一覧が追従すること。
