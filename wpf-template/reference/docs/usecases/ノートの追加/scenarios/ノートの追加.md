# ノートの追加

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者が新しいノートを追加する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 新規作成を指示する | 空の編集画面を表示する |
| 2 | タイトルと本文を入力する | 編集画面で下書きを保持する |
| 3 | 保存を指示する | 入力を検証して DB に確定し、正規化した値を編集画面へ反映して保存完了を表示する |
| 4 | 一覧へ戻る | 一覧を取得し直し、追加したノートを表示する |

## 受け入れ条件

タイトルは前後の空白を除き、本文は入力した値で保存すること。新しい ID と版 1 が SQLite に確定すること。入力・保存のエラーを表示し、保存中は重複実行・離脱・終了を受け付けないこと。一覧の取得失敗で完了済みの保存を失敗へ変更しないこと。
