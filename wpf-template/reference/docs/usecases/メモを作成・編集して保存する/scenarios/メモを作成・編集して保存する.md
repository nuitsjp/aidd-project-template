# メモを作成・編集して保存する

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者が新規メモを作るか、既存メモを編集する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | メモ一覧を開く | 保存されているメモを表示する |
| 2 | 新規または既存のメモを選び、タイトルと本文を入力する | 編集画面で下書きを保持する |
| 3 | 保存を指示する | 入力と版を検証し、DB に確定した値を編集画面へ反映して「保存しました」と表示する |
| 4 | 一覧へ戻る | 一覧を取得し直し、保存したメモを表示する |

## 受け入れ条件

タイトルは前後の空白を除いて保存され、本文・ID・版が SQLite に確定すること。編集画面で保存完了を確認でき、一覧に戻ったときに保存した内容を確認できること。
