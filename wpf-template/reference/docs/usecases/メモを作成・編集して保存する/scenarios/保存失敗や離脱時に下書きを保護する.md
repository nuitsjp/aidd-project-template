# 保存失敗や離脱時に下書きを保護する

- 種別: 拡張
- UI確認: 要

## 分岐条件

入力不正または DB の保存失敗が発生する、または未保存の編集内容がある状態で画面離脱・終了を指示する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 保存を指示して失敗する | 原因を表示し、下書きと既存の保存内容を維持する |
| 2 | 未保存のまま他の画面への移動または終了を指示する | 下書きを破棄するか確認を求める |
| 3 | 確認を取り消す | 画面に留まり、入力内容を維持する |

## 受け入れ条件

入力検証と保存のエラーを確認でき、失敗・離脱取り消しでタイトルと本文が失われないこと。保存処理中は離脱・重複実行を受け付けないこと。
