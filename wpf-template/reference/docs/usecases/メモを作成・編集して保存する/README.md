# メモを作成・編集して保存する

## 主アクター

利用者

## 目的

ローカルのメモを保存し、後から参照・編集・削除する。

## 前提

利用者のデータ領域でアプリが起動している。

## 共通の受け入れ条件

確定したメモを再起動後も参照でき、失敗・確認の取り消しで保存前の内容を意図せず失わないこと。
