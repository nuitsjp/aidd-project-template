# ノートの削除

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者が保存済みノートの詳細を表示している。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 削除を指示する | 対象ノートの削除確認を求める |
| 2 | 確認を取り消す | DB を変更せず、詳細の表示を維持する |
| 3 | 再度削除を指示して承認する | 詳細の取得時の版を検査して対象だけを削除し、取得し直した一覧を表示する |

## 受け入れ条件

承認時は対象だけを削除し、他のノートを維持すること。版が一致しない場合や DB の削除失敗は確定せず、対象と詳細の表示を維持して原因を示すこと。削除結果は再起動後も保持されること。
