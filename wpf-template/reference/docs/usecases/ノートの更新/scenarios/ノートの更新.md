# ノートの更新

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者が保存済みノートの詳細を表示している。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 編集を指示する | 詳細で取得した値と版を編集画面の下書きとして保持する |
| 2 | タイトルと本文を変更する | 変更した下書きを保持する |
| 3 | 保存を指示する | 入力と取得時の版を検証して DB に確定し、正規化した値を編集画面へ反映して保存完了を表示する |
| 4 | 一覧へ戻る | 一覧を取得し直し、更新したノートを表示する |

## 受け入れ条件

タイトルは前後の空白を除き、本文は入力した値で保存すること。同じ ID を維持し、版を 1 増やすこと。版競合・対象なし・入力不正・保存失敗を表示し、保存済みの値を上書きしないこと。保存中は重複実行・離脱・終了を受け付けず、後続の一覧取得失敗で保存成功を変更しないこと。
