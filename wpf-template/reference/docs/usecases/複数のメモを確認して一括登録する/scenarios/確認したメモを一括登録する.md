# 確認したメモを一括登録する

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者が複数のメモを一度に登録する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 一括入力の画面で複数行を入力する | 下書きを保持し、入力を受け付ける |
| 2 | 内容の確認を指示する | 件数と値を検証し、正規化後のタイトルと本文を一覧にする |
| 3 | 確認した内容の一括登録を指示する | 全件を再検証して一体で確定し、登録完了を表示する |

## 受け入れ条件

確認時点で DB は変化せず、確定後は確認した全件の値と版が SQLite に保存されること。
