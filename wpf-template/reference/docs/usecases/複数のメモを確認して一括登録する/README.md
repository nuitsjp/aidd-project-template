# 複数のメモを確認して一括登録する

## 主アクター

利用者

## 目的

複数のメモを入力し、確認した内容を一体で保存する。

## 前提

一括入力の画面を開いている。入力行の形式は [WPF 固有設計](../../architecture-wpf.md) に従う。

## 共通の受け入れ条件

確認前または確認失効後に登録を確定せず、一括登録が成功した時だけ全件が保存されること。未保存入力からの離脱・終了を取り消すと下書きを維持すること。
