# ノート詳細の表示

- 種別: 主成功
- UI確認: 要

## 開始条件

一覧に保存済みのノートが表示されている。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 一覧の行で詳細の表示を指示する | 選択した ID で DB の最新のノートを取得し、タイトルと本文を読み取り専用で表示する |
| 2 | 一覧へ戻る | 一覧を取得し直して表示する |

## 受け入れ条件

一覧の取得後に更新された値も詳細に反映すること。詳細は読み取り専用で、取得に成功した場合に編集画面への移動と削除ができること。対象なしや取得失敗を確認でき、編集・削除できないこと。
