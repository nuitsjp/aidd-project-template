# メモを作成・編集して保存する

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者が自身のメモを作成または編集する。

## 手順

| 手順 | アクター | 操作・処理 |
| --- | --- | --- |
| 1 | 利用者 | 自身のメモ一覧を表示する |
| 2 | 利用者 | 新規メモまたは既存メモを選択し、タイトル・本文を入力する |
| 3 | 利用者 | 保存を指示する |
| 4 | システム | 入力を検証し、SQLite へ更新を確定する |
| 5 | システム | 保存結果を表示し、一覧を更新する |

## 受け入れ条件

保存したメモの所有者・値・版が SQLite に確定し、保存結果と更新された一覧を確認できること。
