# UC-2. CSVの内容を確認して一括登録する

- 主アクターと目的: 利用者が複数のメモを確認してまとめて追加する（[プロジェクトの目的と範囲](../project.md) との対応）
- 主成功系列（UC-2-M、UI 確認: 要）:

| 手順 | アクター | 操作・処理 |
| --- | --- | --- |
| 1 | 利用者 | CSV を入力する（システムは既存件数を表示） |
| 2 | 利用者 / Go | 確認を指示する。Go が CSV を解析して登録候補を返す |
| 3 | 利用者 | 確認画面で候補を確認する（入力画面へ戻っても CSV は保持） |
| 4 | 利用者 / Go | 実行を指示する。Go が同じ CSV を再検証し、進捗を通知しながら全件を一括保存する |
| 5 | システム | 確定件数を表示し、一覧を再取得する |

- 拡張（系列 ID の末尾は -X1 から。着手した系列のみ記載）:

| 系列 ID | 分岐点 | 条件 | 動作 | UI 確認 | 理由 |
| --- | --- | --- | --- | --- | --- |

- 受け入れ条件: プレビュー段階では保存しないこと。全件検証が成功した場合のみ追加し、途中失敗や中止時は一部のみ追加しないこと。演出目的の待機時間を設けず、件数が少ない場合は進捗表示が瞬時に終わってよい。中止要求と確定が重なる場合は保存されなかったと断定せず、一覧で結果を確認する（UI 上の中止要求と Go での中止完了を区別する）。
