# UC-2. CSVの内容を確認して一括登録する

主アクター: 利用者。目的: 複数のメモを確認してまとめて追加する。[実現パターン](../design/UCP-2.md)は UCP-2 です。

## 主成功系列 UC-2-M（UI確認: 要）

| 手順 | アクター | 操作・処理 |
| --- | --- | --- |
| 1 | 利用者 | CSV を入力する（システムは既存件数を表示） |
| 2 | 利用者 / Go | 確認を指示する。Go が CSV を解析して登録候補を返す |
| 3 | 利用者 | 確認画面で候補を確認する（入力画面へ戻っても CSV は保持） |
| 4 | 利用者 / Go | 実行を指示する。Go が同じ CSV を再検証し、進捗を通知しながら全件を一括保存する |
| 5 | システム | 確定件数を表示し、一覧を再取得する |

受け入れ条件: プレビュー段階では保存しないこと。全件検証が成功した場合のみ追加し、途中失敗や中止時は一部のみ追加しないこと。演出目的の待機時間を設けず、件数が少ない場合は進捗表示が瞬時に終わってよいこと。

中止要求と確定が重なる場合は保存結果を断定せず、一覧で実状態を確認します。UI 上の中止要求と Go での中止完了を区別します。
