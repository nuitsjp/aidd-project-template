# UC-2. CSVの内容を確認して一括登録する

主アクターは利用者。目的は複数のメモを確認してまとめて追加すること。[実現パターン](../architecture.md#patterns)はUCP-2。

## 主成功系列 UC-2-M

1. 利用者がCSVを入力する。システムは既存メモの件数を示す。
2. 利用者が確認を指示する。GoがCSVを解析し、登録候補を返す。
3. 利用者が確認画面で候補を確認する。入力画面へ戻ってもCSVを保持する。
4. 利用者が実行を指示する。Goが同じCSVを再検証し、進捗を通知して全件を一括保存する。
5. システムが確定した件数を示し、メモ一覧を再取得する。

受け入れ条件: プレビューだけでは保存しない。全件の検証が成功した場合だけ追加する。確定前の中止・エラーでは一部だけ追加しない。処理時間を演出する待機はしない。件数が少ない場合に進捗表示が瞬時に終わってよい。

中止要求と確定が重なる場合は、保存されなかったと断定せず、一覧で結果を確認する。UI上の中止要求とGoでの中止完了を区別する。
