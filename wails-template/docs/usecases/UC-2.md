# UC-2. CSVの内容を確認して一括登録する

主アクター: 利用者。目的: 複数のメモを確認してまとめて追加する。[実現パターン](../architecture.md#patterns)は UCP-2。

## 主成功系列 UC-2-M

1. 利用者が CSV を入力する（システムは既存件数を表示）。
2. 利用者が確認を指示し、Go が CSV を解析して登録候補を返す。
3. 利用者が確認画面で候補を確認する（入力画面へ戻っても CSV は保持）。
4. 利用者が実行を指示し、Go が同じ CSV を再検証して、進捗を通知しながら全件を一括保存する。
5. システムが確定件数を表示し、一覧を再取得する。

受け入れ条件: プレビュー段階では保存しないこと。全件検証が成功した場合のみ追加し、途中失敗や中止時は一部のみ追加しないこと。演出目的の待機時間は設けず、件数が少ない場合は進捗表示が瞬時に終わってよい。

中止要求と確定が重なる場合は、保存されなかったと断定せず、一覧で結果を確認する。UI 上の中止要求と Go での中止完了を区別する。
