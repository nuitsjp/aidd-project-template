# UC-1. メモを作成・編集して保存する

主アクター: 利用者。目的: 入力内容を保存し、後から確認・編集できるようにする。[実現パターン](../architecture.md#patterns)は UCP-1。

## 主成功系列 UC-1-M

1. 利用者が新規作成または一覧からメモを選択する。
2. システムが保存済み内容を表示し、利用者がタイトル・本文を編集する。
3. 利用者が保存を指示する。Go が入力を検証し、一体で保存する。
4. システムが保存結果と更新された一覧を表示する。

受け入れ条件: 再読み込み・再起動後も保存内容を取得できること。同一 ID の編集で件数が増加しないこと。再取得で未保存の下書きを上書きしないこと。

## 拡張 UC-1-X1

入力不正や保存失敗時は下書きを保持して原因を表示する。未保存状態からの画面遷移や終了時は確認を求め、取り消し時は下書きを維持する。保存処理中に破棄して移動しない。
