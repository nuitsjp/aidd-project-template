# UC-1. メモを作成・編集して保存する

- 主アクターと目的: 利用者が入力内容を保存し、後から確認・編集できるようにする（[プロジェクトの目的と範囲](../project.md) との対応）
- 主成功系列（UC-1-M、UI 確認: 要）:

| 手順 | アクター | 操作・処理 |
| --- | --- | --- |
| 1 | 利用者 | 新規作成または一覧からメモを選択する |
| 2 | システム / 利用者 | 保存済み内容を表示し、利用者がタイトル・本文を編集する |
| 3 | 利用者 / Go | 保存を指示する。Go が入力を検証し、一体で保存する |
| 4 | システム | 保存結果と更新された一覧を表示する |

- 拡張（系列 ID の末尾は -X1 から。着手した系列のみ記載）:

| 系列 ID | 分岐点 | 条件 | 動作 | UI 確認 | 理由 |
| --- | --- | --- | --- | --- | --- |
| UC-1-X1 | 手順3 | 入力不正・保存失敗、または未保存状態での画面遷移・終了 | 下書きを保持して原因を表示する。遷移・終了時は確認を求め、取り消し時は下書きを維持する。保存処理中は破棄して移動しない | 要 | エラー表示と離脱確認の振る舞いを画面で決める必要がある |

- 受け入れ条件: 再読み込み・再起動後も保存内容を取得できること。同一 ID の編集で件数が増加しないこと。再取得で未保存の下書きを上書きしないこと。
