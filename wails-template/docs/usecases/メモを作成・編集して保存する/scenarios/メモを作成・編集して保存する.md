# メモを作成・編集して保存する

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者がメモを新規作成または編集する。

## 手順

| 手順 | アクター | 操作・処理 |
| --- | --- | --- |
| 1 | 利用者 | 新規作成または一覧からメモを選択する |
| 2 | システム / 利用者 | 保存済み内容を表示し、利用者がタイトル・本文を編集する |
| 3 | 利用者 / Go | 保存を指示する。Go が入力を検証し、一体で保存する |
| 4 | システム | 保存結果と更新された一覧を表示する |

## 受け入れ条件

再読み込み・再起動後も保存内容を取得できること。同一 ID の編集で件数が増加しないこと。
